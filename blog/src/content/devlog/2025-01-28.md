Today I set up this devblog to document the SignLingo journey. Using Astro for the static site generation — it's fast, has great markdown support, and deploys easily to Netlify.

## What I built

- Custom header with SignLingo branding
- Dev log section for daily updates (you're reading it!)
- Blog section for longer-form posts
- Mobile-responsive design
- RSS feed for subscribers

## Tech choices

Went with Astro because:
- Zero JS by default = fast pages
- Native markdown/MDX support
- Easy Netlify deployment
- Content collections for type-safe frontmatter
